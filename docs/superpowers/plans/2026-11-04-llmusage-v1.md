# LLMUsage v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App menu bar macOS (SwiftUI) hiển thị % hạn mức gói của Claude, Codex và Grok, kèm thông báo khi gần chạm giới hạn và khi reset.

**Architecture:** Swift Package local `UsageCore` (không SwiftUI) chứa model, các provider (Claude qua HTTPS, Codex/Grok qua JSON-RPC stdio với CLI của họ), logic cảnh báo và `UsageStore` `@Observable`. Target app SwiftUI mỏng, sinh bằng XcodeGen, chỉ lo UI (`MenuBarExtra`, popover, Settings) và tích hợp hệ thống (notification, login item).

**Tech Stack:** Swift 6.4 / Xcode 27, SwiftUI, Observation, Swift Testing, `swiftlang/swift-subprocess` 1.x, XcodeGen 2.46.

**Spec:** `docs/superpowers/specs/2026-11-04-llm-usage-menubar-design.md`. Tài liệu spike (format thật + fixture): `docs/superpowers/spikes/`.

## Review Focus

1. **Người dùng bấm "Deny" ở hộp thoại Keychain.** Phải fallback sang file credential, không được báo `unexpectedFormat` hay crash. Test nằm ở Task 6: `deniedKeychainFallsBackToFile`.
2. **CLI in dòng không phải JSON ra stdout** (banner update, cảnh báo). JSON-RPC client phải bỏ qua dòng đó và chờ response. Test ở Task 2: `callSkipsNonJSONLines`.
3. **`resetsAt` đã qua nhưng server chưa cập nhật %.** UI phải hiện "resetting…", không được hiện countdown âm. Test ở Task 1: `resetDescriptionOverdue`.
4. **`usedPercent` > 100** (dùng quá hạn mức hoặc overage) **hoặc < 0.** Thanh tiến độ phải clamp về 0…1, con số vẫn hiện giá trị thật, mức hiển thị là critical. Test ở Task 1: `fractionClamps`, `usageLevelBoundaries`.
5. **Máy thức dậy sau một thời gian dài offline, lúc backoff đang kéo dài.** Refresh khi wake là refresh `force`, phải bỏ qua backoff mạng (nhưng vẫn tôn trọng `minimumInterval` của Grok). Test ở Task 9: `forceIgnoresBackoffButNotMinimumInterval`.

  - `protocol ProcessRunner: Sendable { func run<R: Sendable>(executable: URL, arguments: [String], environment: [String: String], body: @Sendable (any LineChannel) async throws -> R) async throws -> R }`. Tham số `environment` là các biến **thêm vào** môi trường kế thừa.

  - `final class JSONRPCClient { init(channel: any LineChannel, includesVersionField: Bool); func call(_ method: String, params: JSONValue) async throws -> Data; func notify(_ method: String, params: JSONValue?) async throws }`. `call` trả về JSON thô của field `result`.
  - `struct TimeoutError: Error, Equatable {}`; `func withTimeout<R: Sendable>(_ timeout: Duration, _ operation: @escaping @Sendable () async throws -> R) async throws -> R`
  - Hỗ trợ test: `final class ScriptedChannel: LineChannel`. Có `init(responder: @escaping (JSONValue) -> [String])` (mỗi request gửi đi được parse ra, responder trả về các dòng cần đưa vào hàng đợi), `init(lines: [String])`, và `var hangsWhenEmpty = false`. Khi hàng đợi rỗng, `receive()` trả về `nil`, hoặc treo cho tới khi bị cancel nếu `hangsWhenEmpty`. Thuộc tính quan sát: `sent: [JSONValue]`, `inputFinished: Bool`. `final class FakeProcessRunner: ProcessRunner, @unchecked Sendable` có `init(channel:)`, ghi lại `executable/arguments/environment` và `runCount`.
